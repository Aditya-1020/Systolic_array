# sysarray\_csr: Register Map and Addressing

Control/status registers for the systolic array. APB4 slave, 32-bit, generated by PeakRDL-regblock from `sysarray_csr_fixed.rdl`. Do not hand-edit the generated `.sv`/`_pkg.sv`; change the RDL and regenerate.

## Addressing rules

- **Window:** `paddr` is 7 bits, so the block decodes `0x00` to `0x7F`. Registers occupy `0x00` to `0x47` (`SYSARRAY_CSR_SIZE = 0x48`). Place the base on a 128-byte boundary in the interconnect; the block only sees `paddr[6:0]`.
- **Width/alignment:** every register is 32-bit at a word offset. `paddr[1:0]` is dropped, so an unaligned access silently aliases to the containing word.
- **Byte strobes:** `pstrb` is honoured per byte lane on writes. `pprot` is ignored.
- **No error responses:** `PSLVERR` is tied low. Reads of reserved/unmapped offsets return `0`, writes to them are ignored, and writes to read-only fields are ignored. A wrong offset is invisible on the bus.
- **Timing:** one access phase, no wait states. Read and write latency are balanced.
- **Reads of `COMMAND` return 0** (write-only).
- **Reset values:** all software-writable fields reset to `0`, except `LP_CTRL.AUTO_GATE_EN`, which resets to `1`. Read-only status fields are driven by hardware.

## Bit fields

| Register | Bits | Field | Notes |
| --- | --- | --- | --- |
| COMMAND | 0 | LOAD\_WEIGHTS | Fetch bias (if BIAS\_EN) and weights. Accepted only when idle. |
|  | 1 | START | Stream ACT\_COUNT rows. Needs WEIGHTS\_LOADED, accepted only when idle. |
|  | 2 | ABORT | Stop issuing, discard in-flight results. Keeps WEIGHTS\_LOADED. |
|  | 3 | SOFT\_RESET | ABORT + forget weights + clear control state. Config CSRs and ERROR\_STATUS are kept. |
| STATUS | 0 | BUSY | Any work or memory transaction outstanding (also during flush). |
|  | 1 | WEIGHTS\_LOADED | Weights (and bias) resident. |
|  | 2 | COMPUTING | First row issued until last result written. |
|  | 3 | STALLED | Backpressure or memory wait (live level). |
|  | 4 | DONE | Sticky, W1C. Also cleared by SOFT\_RESET or the next accepted START. Hardware set beats W1C. |
| ERROR\_STATUS | 0 | READ\_ERR | Memory read response error. |
|  | 1 | WRITE\_ERR | Memory write response error. |
|  | 2 | CFG\_ERR | ACT\_COUNT == 0 or misaligned base address. |
|  | 3 | CMD\_ERR | Illegal sequence (START without weights, LOAD/START while busy, ARRAY\_EN=0, LOAD+START together, any command during flush). |
| INT\_ENABLE | 0 | DONE\_IE |  |
|  | 1 | ERROR\_IE |  |
| ARRAY\_CFG | 0 | ARRAY\_EN | 0 forces datapath clock gates off; only ABORT/SOFT\_RESET are legal. |

| POSTPROC\_CFG | 0 | RELU\_EN |  |

| POSTPROC\_MULT | 14:0 | MULT | Unsigned. Bits 31:15 read 0. |

## Behaviour to know

- **Config timing:** *layer-static* registers (ARRAY\_CFG.BIAS\_EN, BIAS\_ADDR, WEIGHT\_ADDR) are captured when LOAD\_WEIGHTS is accepted. *Run-static* registers (POSTPROC\_\*, ACT\_ADDR, DST\_ADDR, ACT\_COUNT) are captured when START is accepted. Writing them while BUSY is legal and applies to the **next** command.
- **Command priority:** SOFT\_RESET > ABORT > LOAD\_WEIGHTS / START. Never set LOAD\_WEIGHTS and START in the same write (CMD\_ERR).
- **W1C clears:** write a 1 to the bit position. To clear DONE write `0x10` to STATUS, not `0x1`. Errors are cleared by writing the matching bit to ERROR\_STATUS.
- **Interrupt:** the block exports `hwif_out.STATUS.intr` and `hwif_out.ERROR_STATUS.intr`; INT\_ENABLE is only stored, not applied. The top level must build `irq = (STATUS.intr & DONE_IE) | (ERROR_STATUS.intr & ERROR_IE)`.
- **Narrow fields:** MULT and SHIFT are sized for MULT\_W=16 and SHIFT\_W=6; the wrapper slices them.

## Typical sequence

1. `ARRAY_CFG` = `ARRAY_EN` (+ `BIAS_EN` if used).
2. Write `WEIGHT_ADDR` (and `BIAS_ADDR`), then `COMMAND` = `0x1`. Poll `STATUS.WEIGHTS_LOADED` and `!BUSY`.
3. Write `ACT_ADDR`, `DST_ADDR`, `ACT_COUNT`, `POSTPROC_*`, then `COMMAND` = `0x2`.
4. Wait for `STATUS.DONE` (poll or IRQ), check `ERROR_STATUS`, then write `0x10` to `STATUS` to clear DONE.
